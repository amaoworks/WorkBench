# Wallos 订阅待办联动

在「设置 → 业务模块 → 待办 → 设置」填写 Wallos 的部署地址与当前用户的 API Key，启用自动同步，保存后点击「立即同步」。地址可以包含部署子路径，例如 `https://example.com/wallos`。工作台服务端必须能够访问该地址；支持自托管内网 HTTP 和证书有效的 HTTPS。

## 提醒规则

- 默认提前 3 天、`Asia/Shanghai` 时区上午 9 点提醒，可设置提前 0–90 天、小时 0–23 和 IANA 时区。
- 后台每小时同步一次所有有效订阅，将付款日期在当前自然月的订阅提前加入待办；月份按配置时区判断。生成待办时同时设置提醒时间，到指定时间后由每分钟扫描发送站内通知，不会因为提前生成就立即提醒。
- 例如 9 月 20 日付款、提前 3 天上午 9 点提醒：9 月首次同步即加入待办，9 月 17 日上午 9 点触发提醒。
- 对于跨月提前提醒（例如 10 月 1 日付款、9 月 28 日提醒），进入提醒时间后也会加入待办；这类新生成提醒最多等待约一小时同步。已过提醒时间、Wallos 仍返回的账单也会补入并提醒。
- 周付、月付、季付、半年付、年付及自定义周期由 Wallos 管理。工作台读取 `next_payment`，不会自行推算或修改付款周期，也不会把完成待办当作实际付款。
- 待办标题为「Wallos续费提醒 - 订阅名称」，说明按顺序显示分类、支付方式、付款日期（含时区）、原币金额 → 人民币金额和「请及时付款！」；待办的到期时间是提前提醒的时间。
- 以 Wallos 地址、订阅 ID、付款日期去重，重复同步、重启、完成待办都不会重建同一期；删除待办后，若该账单仍符合导入条件，下次同步会重新生成（兼容此前已删除的待办）。下一账期付款日期进入当月，或已达到提前提醒时间时，生成新待办。
- 提醒配置只影响未生成的待办；再次同步同一账期时会更新标题与说明（含分类、支付方式和金额），保留提醒时间和完成状态，已删除的待办可重新生成。远端停用/删除订阅不会删除已有待办，远端修改付款日期会视作新的付款日期。需要调整已有提醒时，可删除原待办。
- 停用联动或整个待办模块会停止后续同步，历史待办保留。停用联动后，已生成且未完成的到期待办仍走正常提醒流程。
- 错过运行期间，只能补充 Wallos 当前仍返回的付款日期；不会重建 Wallos 已经滚动过去的历史账期。Wallos 自身的日期更新定时任务须正常运行。

## 连接与数据

使用 Wallos 官方接口 [`api/subscriptions/get_subscriptions.php`](https://github.com/ellite/Wallos/blob/main/api/subscriptions/get_subscriptions.php)，通过表单 POST 传递 `api_key` 与 `state=0`。接口须返回 `success: true` 和 `subscriptions` 数组（包含 `id`、`name`、`next_payment`、`inactive`）。这是单向读取集成，不需要配置 webhook，也不修改 Wallos。

API Key 保存于工作空间数据库，不通过读取配置接口回显，也不放在请求 URL 中。留空保留已有密钥；更换地址须重新填写密钥。清空地址并关闭联动可以清除保存的密钥。数据库和备份包含凭据，应妥善保管。

请求超时 20 秒，不跟随重定向，响应上限 4 MiB / 10000 条订阅。无效响应或任何有效订阅的必要字段错误会拒绝本批写入；事件、待办和去重记录在同一事务提交。设置中展示最近成功同步时间及最近错误。同步失败保留已有待办，下个周期会重试。

配置接口及手动同步接口受工作台现有鉴权、CSRF 和业务模块启停控制：

- `GET /api/modules/todo/wallos`：配置（不含密钥）、`hasApiKey`、`lastSync`、`lastError`。
- `PUT /api/modules/todo/wallos`：保存 `enabled`、`baseUrl`、`apiKey`、`daysBefore`、`reminderHour`、`timeZone`。
- `POST /api/modules/todo/wallos/sync`：同步已保存配置，返回本次新建数 `created`。

本功能已用模拟 Wallos 服务验证请求格式、子路径、错误处理和账期流程；实际实例的版本及网络兼容性需填写配置后通过「立即同步」确认。

分类和支付方式分别读取 `category_name`、`payment_method_name`。原币金额保留订阅的 `price`，通过 `currency_id` 关联 [货币接口](https://github.com/ellite/Wallos/blob/main/api/currencies/get_currencies.php) 的币种与汇率。人民币金额按 `原币金额 × CNY汇率 ÷ 原币汇率` 计算，使用十进制精确运算并四舍五入到两位小数；汇率来自 Wallos 保存的数据，不代表实际支付结算价。缺少币种或有效汇率时明确显示无法换算，不假设 1:1。货币接口请求失败时本次同步失败，保留现有待办。
